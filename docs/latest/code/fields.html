Fields and coordinates#

Unit-aware mode fields and integrated modal observables.

Analytical fields have an arbitrary overall amplitude. Attaching V/m and A/m expresses the solver’s electric/magnetic convention; absolute optical power requires choosing an amplitude normalization.
